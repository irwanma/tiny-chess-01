A 4 KB Python chess engine: 0x88 board, negamax with PVS, null-move pruning, LMR, futility and delta pruning, check extension, transposition table, killer moves and history heuristic, CPW piece-square tables with an endgame king blend and bishop-pair bonus. Fixed 240,000-node budget per move, fully deterministic — no clock, no randomness.

## Run it

```sh
python3 main.py
```
